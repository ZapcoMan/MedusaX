## 参数

| 命令 | 参数数量 | 作用                                                         | 说明                                                         |
| ------- | -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| -u      | 1                    | 输入单个 url（最好使用 `http://` 或 `https://` 开头，url 后面不要跟任何参数 | 例如：`-u https://www.ascotbe.com` 或 `-u https://192.168.0.1` |
| -a      | 1                    | 指定 header 头或使用随机 header                             | 使用此功能时，请参阅文档中该内容的说明 |
| -f      | 1                    | 文件名包含要扫描的 url                                        | `-u` 或 `-f` 必须存在且仅存在一个                           |
| -p      | 1                    | 需要填写代理的 IP，如果有端口需要带上端口                     | 使用 BURP 作为代理时，应传入 127.0.0.1:8080                  |
| -m      | 1                    | 扫描单个模块，例如：Struts2 或 Apache 等                      | 具体内容可输入项目 Modules 文件夹中对应的名称。               |
| -t      | 1                    | 进程数设置，默认（-t 5）                                      | 无                                                           |
| -s      | 1                    | 启用子域名探测                                                |                                                              |
| -PL     | 1                    | 列表形式的端口                                                | 只要用非数字分隔即可，超过 65535 的端口将被剔除。如果不输出 -p 或 -P，将扫描默认端口。例如：22,139,445,3389 |
| -PR     | 1                    | 范围形式的端口                                                | 只要用非数字分隔即可，超过 65535 的端口将被剔除。如果不输出 -p 或 -P，将扫描默认端口。例如：1-65535 |

## 环境配置

### 系统环境配置

> Ubuntu

需要安装 `JAVA` 环境，并且 `java` 命令可以在全局变量中执行

> CentOS

1. 需要安装 `JAVA` 环境，并且 `java` 命令可以在全局变量中执行

2. 需要执行 `yum install sqlite*` 命令来安装 **sqlite3.so** 库

> Mac OS

需要安装 `JAVA` 环境，并且 `java` 命令可以在全局变量中执行

### 安装 Python 环境

当前插件是在 `Python3.7.x` 环境下开发的。低于 `3.7` 版本，某些功能无法使用。如果需要使用扫描器或编写插件，必须先安装 `Python` 开发环境。建议使用 `PyCharm` + `Anaconda` 作为开发环境。

### 安装依赖

运行 Medusa 所需的包在根目录下执行

```python
pip install -r Medusa.txt
```

## 配置文件

本节所指的配置文件是同一个文件

#### 0x01 DNSLOG

由于我自建的 `DNSLOG` 不支持某些协议，目前检测第三方平台有两种方法

> 第一种方法（默认）

第一种是默认方法，无需修改，方便快捷

> 第二种方法

使用 http://ceye.io/ 中的 `DNSLOG`，此方法需要修改配置文件

```
#在根目录（Medusa 目录）打开此文件
vim config.py
```

将 `ceye_dnslog_url` 和 `ceye_dnslog_key` 更改为你在 http://ceye.io/ 的 `Identifier` 和 `API Token` 的值，然后将 `dnslog_name` 更改为 `ceye`

**注意：** 使用脚本时，确保网络畅通。如果没有扫描到漏洞，不妨看看 `DNSLOG` 数据是否存在

#### 0x02 调试模式

此模式默认关闭。如果需要打开，请修改 `config.py` 文件中的参数

```
#默认
debug_mode = False
#打开 Debug 模式
debug_mode = True
```

此模式的输出内容不是进度条和模块加载内容，而是变为每个插件的错误信息

#### 0x03 多线程

由于重构将之前的多线程替换为多进程，单个插件中的 for 循环替换为多线程，因此默认线程数为 **15**。如果需要修改，请将配置文件中的 `thread_number` 值更改为你需要的线程数

```
thread_number=15 #默认线程数
```

## 快速开始

该工具仍处于测试阶段。如有任何问题，请提交 `issues`。请记住，此扫描器仅用于授权测试

#### 0x01 使用扫描器扫描单个网站

注意：建议放入完整路径，某些插件需要使用完整路径名，例如：`Struts2`

```bash
python3 MedusaScan.py -u https://www.ascotbe.com
```

#### 0x02 使用扫描器扫描一批网站

`Ascotbe.txt` 是你存储的文件。最好将其放在与 `MedusaScan.py` 文件相同的目录中。你存储 `URL` 的文件格式为每行一个 `url`

文件需要注意几个规范

- 需要填写 `url` 且每行一个 `url`

- `url` 需要带上 `http://` 或 `https://`，如果两个协议都需要扫描，可以写成两行

- 如果单个 `url` 中的不同端口对应不同的服务，你需要将它们写出来。例如，**8080** 和 **1024** 对应不同的服务，如果你想全部扫描，需要按以下形式编写

  ```
  http://ascotbe.com:1024/test
  http://ascotbe.com:8080/test
  ```

- 不同的子目录，如 `test` 和 `medusa`，也需要分行编写

  ```
  http://ascotbe.com:1024/test
  http://ascotbe.com:1024/medusa
  ```

接下来运行以下命令开始扫描

```bash
python3 MedusaScan.py -f Ascotbe.txt #你的文件最好放在与 MedusaScan 同级的目录
```

#### 0x05 HTTP 请求相关配置

需要在 **config.py** 配置文件中配置

```bash
#########################################################################
#requests 配置
#########################################################################
user_agent_randomization=False#是否在 header 中启用随机化，默认禁用
user_agent_browser_type="chrome"#目前仅支持以下浏览器。修改为其他浏览器可能导致不可用。
                                #firefox、ie、msie、opera、chrome、AppleWebKit、Gecko、safari
#默认请求头，保存必要数据，如果启用随机化，User-Agent 头数据将会改变
# WEB 版本添加一个判断，如果用户传入 header，该 header 将被覆盖
headers={
    "Connection": "close",
    "User-Agent": "Mozilla/5.0 (Macintosh; Intel Mac OS X 11_0_1) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/87.0.4280.88 Safari/537.36",
    "Accept": "*/*",
    "Accept-Encoding": "gzip, deflate",
    "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
    "dnt": "1"
}
#如果你不想使用代理，请将以下参数替换为：proxies=None
proxies = {
  "http": "http://127.0.0.1:8080",
  "https": "https://127.0.0.1:8080",
}
```

#### 0x06 扫描单个模块

请使用模块支持的名称作为根文件夹。一个文件夹名对应一个模块，请注意大小写。实在无法理解，请参考[此文件](https://www.ascotbe.com/Medusa/Documentation/#/PluginDirectory)中的名称

```bash
python3 MedusaScan.py -u https://www.ascotbe.com -m Struts2
```

#### 0x07 进程设置

开启多进程功能，默认 15 个进程，进程越多速度越快，当一个插件使用 for 循环时，会在进程内启动多线程！

```bash
python3 MedusaScan.py -u https://www.ascotbe.com -t 100 #100 个进程
```

#### 0x09 敏感信息泄露

已集成到模块中，全量扫描会自动启动，如果需要单独扫描，只需输入模块名称

## 结果

1. 输出 `The number of vulnerabilities scanned was: 0` 表示未扫描到漏洞

2. `ScanResult` 目录中除了 `Medusa.txt` 外没有其他文件

3. `Medusa.db` 文件中没有新内容，或者该文件未创建

4. 如果以上三点都不存在，则表示确实没有发现漏洞
