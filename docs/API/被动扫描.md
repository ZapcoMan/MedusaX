### 创建被动扫描项目接口

`/api/create_proxy_scan_project` 用来创建被动扫描项目，如果创建成功返回**200**。创建后可在浏览器或客户端中将 HTTP/HTTPS 代理指向被动扫描代理端口，并填写本项目设置的代理账号与密码，即可开始抓取流量。

```json
{
	"token": "XXXXXX",
	"proxy_project_name": "Soryu Asuka Langley",
	"proxy_username": "ascotbe",
	"proxy_password": "ascotbe",
	"end_time": "1610751014"
}
```

> 参数解释

- `token` 登录后返回给你的**token**
- `proxy_project_name` 项目名称，同一用户下不可重复
- `proxy_username` 代理认证账号
- `proxy_password` 代理认证密码（后端会以 MD5 形式落库）
- `end_time` 项目有效期，秒级时间戳，过期后代理将拒绝该项目的连接

> 返回状态码

- 169：莎酱被玩坏掉嘞QAQ
- 200：项目创建成功👌
- 403：小宝贝这是非法查询哦(๑•̀ㅂ•́)و✧
- 500：请使用Post请求
- 503：项目创建失败（当前用户下已存在同名项目）

### 查询被动扫描项目列表接口

`/api/query_proxy_scan_project` 用来查询当前用户创建的所有被动扫描项目，返回结果是**JSON**格式

```json
{
	"token": "XXXXXX"
}
```

> 参数解释

- `token`登录后返回的**token**

> 返回状态码

- 200：返回项目列表信息

  ```json
  {
  	"message": [{
  		"proxy_id": "P1",
  		"creation_time": "1609054280",
  		"end_time": "1610751014",
  		"status": "1",
  		"proxy_username": "ascotbe",
  		"proxy_project_name": "Soryu Asuka Langley"
  	}, {
  		"proxy_id": "P2",
  		"creation_time": "1609054345",
  		"end_time": "0",
  		"status": "0",
  		"proxy_username": "ascotbe",
  		"proxy_project_name": "内网资产流量审计"
  	}],
  	"code": 200
  }
  ```

  > 返回参数解释

  **会有多个数组的集合**

  - `proxy_id` 项目ID
  - `creation_time` 项目创建时间（秒级时间戳）
  - `end_time` 项目到期时间（秒级时间戳，`0` 表示永久）
  - `status` 项目状态，`1` 表示运行中，`0` 表示已停止
  - `proxy_username` 代理账号
  - `proxy_project_name` 项目名称

- 403：小宝贝这是非法查询哦(๑•̀ㅂ•́)و✧

- 500：查询失败或未使用Post请求

### 查询被动扫描流量数据接口

`/api/query_proxy_scan_data` 用来查询某个被动扫描项目抓取到的原始流量数据，返回结果是**JSON**格式

```json
{
	"token": "XXXXXX",
	"proxy_id": "P1"
}
```

> 参数解释

- `token`登录后返回的**token**
- `proxy_id` 项目ID，通过项目列表接口获取

> 返回状态码

- 200：返回流量数据列表

  ```json
  {
  	"message": [{
  		"original_proxy_id": 1,
  		"creation_time": "1609054280",
  		"url": "https://www.example.com/login",
  		"request_method": "POST",
  		"response_status_code": "200",
  		"issue_task_status": "1"
  	}],
  	"code": 200
  }
  ```

  > 返回参数解释

  **会有多个数组的集合**

  - `original_proxy_id` 流量数据ID
  - `creation_time` 抓取时间（秒级时间戳）
  - `url` 请求地址
  - `request_method` 请求方法
  - `response_status_code` 响应状态码
  - `issue_task_status` 检测状态，`1` 表示已进入被动检测，`0` 表示待检测

- 403：小宝贝这是非法查询哦(๑•̀ㅂ•́)و✧

- 500：查询失败或未使用Post请求

### 子域名探测结果查询接口

`/api/subdomain_query` 用来查询某个主动扫描任务探测到的子域名列表，返回结果是**JSON**格式

```json
{
	"token": "XXXXXX",
	"active_scan_id": "1"
}
```

> 参数解释

- `token`登录后返回的**token**
- `active_scan_id` 目标的**active_scan_id**值，通过主动扫描任务列表接口获取

> 返回状态码

- 169：莎酱被玩坏啦ヽ(･ω･´ﾒ)
- 200：返回子域名列表

  ```json
  {
  	"message": [{
  		"url": "www.example.com",
  		"subdomain": "mail.example.com",
  		"timestamp": "1609054280",
  		"active_scan_id": "1"
  	}],
  	"code": 200
  }
  ```

  > 返回参数解释

  **会有多个数组的集合**

  - `url` 目标主域
  - `subdomain` 探测到的子域名
  - `timestamp` 探测时间（秒级时间戳）
  - `active_scan_id` 所属主动扫描任务ID

- 403：嘿~宝贝这是非法查询哦(๑•̀ㅂ•́)و✧

- 404：宝贝没有数据哦🐈

- 500：请使用Post请求
